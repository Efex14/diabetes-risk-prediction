# Diabetes Risk Prediction Using Machine Learning Algorithms

## Project Description

This project predicts possible diabetes risk using machine learning models trained on health, lifestyle, and demographic survey indicators. It includes a complete data science workflow: exploratory data analysis, data quality checks, model training, model evaluation, saved reports and figures, a trained model artifact, and a bilingual Streamlit survey application.

The Streamlit app asks user-friendly health survey questions in English or Turkish, maps the answers to the numeric feature format expected by the trained model, and returns an educational diabetes risk estimate.

## Dataset Used

The dataset used in this project is the CDC Diabetes Health Indicators Dataset. The selected file is `diabetes_binary_health_indicators_BRFSS2015.csv`.

The target variable is `Diabetes_binary`:

- `0`: No diabetes
- `1`: Diabetes or diabetes risk

The dataset includes indicators such as high blood pressure, high cholesterol, BMI, smoking status, physical activity, fruit and vegetable consumption, general health, age category, income, and education. The task is treated as a binary classification problem.

## Machine Learning Models Used

The notebook trains and compares the following models:

- Logistic Regression
- K-Nearest Neighbors
- Decision Tree Classifier
- Random Forest Classifier
- Gradient Boosting Classifier
- XGBoost Classifier

Class imbalance is considered during evaluation, so recall, F1-score, and ROC-AUC are emphasized alongside accuracy and precision.

## Best Model

The selected best model is the **Gradient Boosting Classifier**. It was saved to:

```text
models/best_diabetes_model.pkl
```

## Model Comparison Summary

Model comparison results are saved in:

```text
reports/model_comparison_results.csv
```

Summary of the final comparison:

| Model | Accuracy | Precision | Recall | F1-score | ROC-AUC |
| --- | ---: | ---: | ---: | ---: | ---: |
| Gradient Boosting Classifier | 0.723 | 0.307 | 0.787 | 0.442 | 0.826 |
| Logistic Regression | 0.732 | 0.311 | 0.761 | 0.441 | 0.820 |
| XGBoost Classifier | 0.720 | 0.305 | 0.790 | 0.440 | 0.826 |
| Decision Tree Classifier | 0.704 | 0.292 | 0.787 | 0.426 | 0.806 |
| Random Forest Classifier | 0.858 | 0.469 | 0.160 | 0.239 | 0.792 |
| K-Nearest Neighbors | 0.857 | 0.445 | 0.101 | 0.165 | 0.764 |

Gradient Boosting was selected because it achieved the highest F1-score while maintaining strong recall and ROC-AUC performance. Recall is especially important in diabetes risk prediction because missing high-risk cases can be more harmful than producing false positives in an educational screening context.

## Streamlit App

The project includes a bilingual Streamlit app at:

```text
app/streamlit_app.py
```

The app provides:

- English and Turkish language selection
- Real SVG flag assets for Turkey and the United Kingdom
- A user-friendly health survey interface
- Automatic BMI calculation from height and weight

## Installation

Create and activate a virtual environment, then install the required packages:

```bash
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
```

On systems that use `python` instead of `py`, replace `py` with `python`.

## How to Run the Notebook

Start Jupyter Notebook from the project root:

```bash
jupyter notebook
```

Then open:

```text
notebooks/diabetes_prediction_analysis.ipynb
```

## How to Run the Streamlit App

Run the app from the project root:

```bash
py -m streamlit run app/streamlit_app.py
```

On systems that use `python` instead of `py`, run:

```bash
python -m streamlit run app/streamlit_app.py
```
